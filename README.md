==================== DISCLAIMER ====================
This fan project is non-profit and made for passion. This project is developed for the Steam version of Sword and Fairy 4 (Chinese Paladin 4) only.

In version 0.3.3, in-game content has been tested.
Please notice besides **PAL4 EnglishMod Installer 0.3.3** and  **PAL4 EnglishMod Patch 0.3.3**, there is also a **PAL4 EnglishMod Patch 0.3.3b(No Videos)** which does not contain the video files containing embedded subtitles. For Chapter 1-4 you won't be needing the videos so I recommend 0.3.3b for this early stage.

Known unfinished areas:
- Dialogue text from Chapter 5 onward (out of 9 chapters total)   has not yet received full manual polishing.
- Some help and quest text still has inconsistent line-wrapping rules,  which may affect readability, but the content itself is complete.

Audio note:
- SFX and voice-over volume are tied together.
- If Chinese voice sounds too quiet, set SFX volume to at least 2x of music volume in game settings.
- If you do not want voice-over, press V in-game to toggle voice playback.
